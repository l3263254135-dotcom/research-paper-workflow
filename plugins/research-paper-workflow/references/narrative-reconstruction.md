# Narrative Reconstruction

This reference defines the expression-layer workflow for rebuilding an existing manuscript while preserving its scientific facts.

## Product specification and publication story

Treat the source manuscript as a record of fixed facts: data, analysis, figures, tables, observations, interpretations, limitations, citations, and conclusion boundaries. Treat the rewritten manuscript as a reader-facing scientific story that decides what comes first, what each section must answer, and how evidence accumulates.

The story spine should make the following path explicit:

`research problem -> knowledge gap -> testable question -> evidence sequence -> bounded interpretation -> contribution`

## Internal rewrite order

Write Results first so the evidence sequence is stable. Write Discussion second so each interpretation is tied to a result and alternative explanation. Rewrite Introduction third so the gap and question lead naturally to the stabilized results. Write Conclusion, Abstract, and Title after the body is stable. Align Methods and captions last.

## Source block disposition

Each source block must be marked as `preserve`, `move`, `merge`, `compress`, `supplement`, or `remove_with_reason`. A removal is permitted only when the information is duplicated, outside the target article type, or explicitly retained elsewhere. Material evidence may not disappear because it complicates the story.

## Evidence boundary

Use observation language for direct measurements, bounded inference language for supported interpretation, and explicit uncertainty for unresolved mechanisms. The narrative may become clearer and more persuasive through structure and wording, but its evidence strength must not increase.
