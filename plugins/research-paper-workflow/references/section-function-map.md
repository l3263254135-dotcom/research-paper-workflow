# Section Function Map

| Section | Primary function | Required evidence | Common failure |
|---|---|---|---|
| Title | Identify question, object, design, and bounded contribution | Core claim | Overstated novelty or mechanism |
| Abstract | Compress problem, method, main result, boundary, and implication | Verified core results | Claims stronger than body |
| Introduction | Move from known to unknown to question and contribution | Verified gap and citations | Broad background without a testable gap |
| Results | Answer subquestions in evidence order | Result IDs and figures | Methods diary or interpretation mixed into observations |
| Discussion | Interpret, compare, test alternatives, and state limits | Results, claims, citations | Causality or mechanism inflation |
| Conclusion | State the main supported answer and next testable question | Core claim and limits | New evidence or generalization |
| Methods | Make the study reproducible | Analysis plan and provenance | Black-box configuration |
| Figure captions | Let each figure be interpretable on its own | Figure manifest and result records | Missing units, error definitions, or panel roles |
