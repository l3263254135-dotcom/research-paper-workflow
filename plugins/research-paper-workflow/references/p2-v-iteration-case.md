# P2 v-line lessons for manuscript iteration

This public guide abstracts methods from the v-series workflow. The examples below are illustrative, not a report of unpublished results or of editorial status. Private feedback, manuscript versions, and submission records are not distributed with the plugin.

| Decision | Transferable lesson |
|---|---|
| Identify the iteration baseline | Freeze the actual deliverable and evidence version before revising. Resolve conflicting version labels by checking dated records and hashes. |
| Distinguish alternative mechanisms | Write different observable predictions before computing. Match variables and units, choice of comparator, spatial mask, and analysis window. Diagnose a quantity by what it measures, not by the label attached to it. |
| Spend effort where the conclusion could change | Try a fair comparator or a lower-cost diagnostic before a new experiment. State how support, inconclusive evidence, and contradiction would change the paper. |
| Turn each figure into a test | Specify the question, supporting result, and counterexample or control before drawing. Put evidence that changes a headline claim alongside the claim. |
| Accept negative results without losing verified findings | If a proposed mechanism fails, narrow or remove it; keep independently supported phenomena. If a like-for-like reanalysis overturns the phenomenon, withdraw it and trace the change through figures, prose, and submission metadata. |
| Verify the real deliverable | Compare rendered panel labels and units with source data, not just with a previous style. Test the extracted reproduction archive rather than the staging tree. Separate technical checks from reviewer access, author approval, and portal submission. |

## Example decisions

- **Idea only:** To ask whether terrain alters distant sea ice, lay out signatures that distinguish remote transport from local feedback and identify a minimal test. Do not write a results-based abstract.
- **Phenomenon confirmed, pathway uncertain:** If the expected spring signature is absent but a regional response survives the control, report the regional response and the mechanism uncertainty separately.
- **Finding overturned:** If a mask indexing error created an apparent regional contrast, rerun with the intended mask and remove the claim if the contrast disappears. Do not switch masks to rescue the title.
- **Files verified, submission gates open:** A runnable archive and resolving DOI do not establish access to the files. Verify a journal-permitted review route and obtain author approval for the frozen version separately.
